Game Controls


BASIC GAME CONTROLS
The majority of your control during the game is through using your mouse. The mouse performs the following actions: - SELECTION (LEFT-CLICK): the left mouse button is used to select units, buildings, command buttons and points of action (locations where orders are carried out). - AUTO COMMANDS (RIGHT-CLICK): when you have a unit or group selected, the right mouse button can be used to issue intelligent commands that will automatically be carried out.

CAMERA MOVEMENT
Possible ways to move the game camera include: - using keyboard arrow keys; - clicking and holding the middle mouse button; - moving the cursor to the edges of the screen (this option can be enabled or disabled in the game settings). The speed of camera movement can be adjusted in the game settings.

BASE CONSTRUCTION
You must have at least one builder to build a base. Switch the control panel to "Buildings" tab and click on the building icon to select the type of building you need. If the requirements for the selected building type are not met, the game will display an error message; otherwise, the game will draw the building`s sprite and a circle around the mouse cursor. The radius of the circle is the radius of the building. If the circle is red - the building needs more space, if it is blue - the build place is too far away from the nearest builder, if it is green - the building can be built here.

UNIT PRODUCTION
Any unit may be built if the player has at least one building capable of producing that type of unit, and the unit`s other requirements are met. Switch the control panel to "Units" tab and click on the unit icon. If the requirements for the selected unit type are not met, the game will display an error message. If no unit production building is selected - the game sends the production order to nearest unbusy production building, otherwise it sends the order to nearest unbusy selected production buildings. It is impossible to create a unit production queue.

UPGRADES PRODUCTION
Go to the "Upgrades" tab in the Control Panel and click the upgrade icon. If the requirements for the selected upgrade type are not met, the game will display an error message. If no upgrade production facility is selected - the game sends the production order to any nearest unbusy production facility, otherwise it sends the order to nearest unbusy selected production facilities. It is impossible to create an upgrade production queue.

Game Mechanics


RESOURCES
There are 3 types of resources in the game:
- The main resource of the game is the "Energy level". Almost all production (building construction, unit creation, or upgrade research) in the game consumes this resource. In the user interface, it is displayed as two numbers: the level of free energy and the maximum energy level. When a player starts any production that requires this resource, the game reduces the free energy level by the production cost and restores this amount after the production is completed. The energy level can be increased by specific buildings, as well as special objects on the game map that need to be captured and held.

There are also 2 additional types of resources used for special technologies and abilities:
- Hell power - when playing as the Hell faction, this resource is automatically replenished by the "Altar of Pain" building. The replenishment rate increases with each additional "Altar of Pain", but constructing more than three "Altars of Pain" does not provide any further benefit. When playing as UAC, the resource is generated from destroyed enemy units and Hell structures. Maximum quantity: 15000.
- UAC Loot - this resource is acquired by both factions through the destruction of enemy UAC units and buildings. Maximum quantity: 30000.

ARMY LIMIT
Each units and buildings in the game takes at least 1 limit point. Maximum limit points per each player is 125! Dead units still exist in the game and takes limit.

UNIT ATTRIBUTES
- ALIVE or DEAD;
- UNIT or BUILDING;
- MECHANICAL or BIOLOGICAL;
- LIGHT or HEAVY;
- FLYING or GROUND;
- LEVEL2..4 - unit level if it is higher than 1.

UNIT EFFECTS
- STUNED - unit is stuned and can`t attack or move;
- DETECTOR - unit can see invisible enemy units;
- HEROIC - unit is a hero; its takes half damage and deals double damage;
- SCANED - unit was scanned by UAC radar;
- DECAY AURA - unit is under "Decay Aura" effect;
- HELL VISION - unit is under "Hell Vision" effect; it can see invisible enemy units;
- INVULNERABILITY SPHERE - unit is under "Invulnerability Sphere" effect; it is immune to any damage;
- INVISIBILITY SPHERE - unit is under "Invisibility Sphere" effect; it invisibile;
- DAMAGE RESISTANCE SPHERE - unit is under "Damage Resistance Sphere" effect; it takes half damage;
- DOUBLE DAMAGE SPHERE - unit is under "Double Damage Sphere" effect; it deals double damage;
- TURBO SPHERE - unit is under "Turbo Sphere" effect; it is significantly accelerated.

PAIN STATE Some units have "Pain State" - it is a 1-second stun state after a certain number of damage hits. During the "Pain State" unit can`t attack or move. "Pain State" is accompanied by a special sound and unit animation.

VETERAN SYSTEM
All combat units gain combat experience and increase their level. All units spawn at level 1 and can be upgraded to level 4. With each new level, the unit increases its damage, armor, and pain threshold. In long-range combat, a unit must be in combat for 40 seconds to get next level. In melee it will take half as long for the unit to reach next level.

DAMAGE CALCULATION SEQUENCE
1) The game takes the attacking unit`s base damage and adds bonuses from upgrades and veteran level;
2) Special effects of the attacking unit that affect its damage amount are applied ("HEROIC" attribute and "DOUBLE DAMAGE SPHERE" effect);
3) A damage modifier for the attacking unit is applied to the resulting value;
4) Special effects reducing the received damage by the target unit are applied ("HEROIC" attribute and "DAMAGE RESISTANCE SPHERE" effect);
5) The armor of the target unit is calculated (bonuses from upgrades and its veteran level are summed up) and subtracted from the inflicted damage; if the damage drops below 1, it is raised to 1;
6) The target unit receives the final calculated damage.
Special cases:
- If the unit is a building under construction, steps 4 and 5 are skipped;
- Damage dealt by the "Decay Aura" effect also ignores points 4 and 5;
- Units with BUILDING or MECHANICAL attribute are immune to splash damage.

OTHER
If a player loses all his builders - all his units revealed on the map.

Unit hits regeneration period is 1 second.

Dedicated server
Dedicated server - a special version of the game that does not load any game resources and immediately starts working as a server. To start a dedicated server, run it with the following parameters:
MarsWars_ded.exe [X]
where X - UDP port (optional argument, default value - 10666). Any connected player can change the game settings in a dedicated server`s lobby. The game will start automatically as soon as all players mark the "ready" option. The server will return to the lobby one minute after the game ends or immediately after all players leave the server.
