Game Controls


BASIC GAME CONTROLS
The majority of your control during the game is through using your mouse. The mouse performs the following actions:
- SELECTION: the "Mouse left button" is used to select units, buildings, command buttons and points of action (locations where orders are carried out).
- AUTO COMMANDS: when you have a unit or group selected, the "Mouse right button" can be used to issue intelligent commands that will automatically be carried out.

CAMERA MOVEMENT
Possible ways to move the game camera include:
- using keyboard arrow keys;
- clicking and holding the "Mouse middle button";
- moving the cursor to the edges of the screen (this option can be enabled or disabled in the game settings).
The speed of camera movement can be adjusted in the game settings.

BASE CONSTRUCTION
You must have at least one builder to build a base. Switch the control panel to "Buildings" tab and click on the building icon to select the type of building you need(or press the associated hotkey). If the requirements for the selected building type are not met, the game will display an error message; otherwise, the game will draw the building`s sprite and a circle around the mouse cursor. The radius of the circle is the radius of the building. If the circle is red - the building needs more space, if it is blue - the build place is too far away from the nearest builder, if it is green - the building can be built here. To deselect a building type, press "Mouse right button". Hold "Ctrl" to disable position pushing from obstacles. To cancel the construction of a building, select it and issue the "Cancel production (Ctrl+C)" or "Self-destruction (DELETE)" order. Note: each player cannot have more than 4 builders.
NOTE: losing your buildings affect your construction system into short cooldown effect.
TIP: build buildings close to each other - units will not get stuck between them.

UNIT PRODUCTION
Any unit may be built if the player has at least one building capable of producing that type of unit, and the unit`s other requirements are met. Switch the control panel to "Units" tab and click on the unit icon(or press the associated hotkey or hover your mouse over the unit icon and scroll the "Mouse wheel up"). If the requirements for the selected unit type are not met, the game will display an error message. If no unit production building is selected - the game sends the production order to nearest unbusy production building, otherwise it sends the order to nearest unbusy selected production buildings. It is impossible to create a unit production queue. To cancel unit production process, click "Mouse right button" on the unit icon or select production buildings and issue then "Cancel production (Ctrl+C)" order.

UPGRADES PRODUCTION
Go to the "Upgrades" tab in the Control Panel and click the upgrade icon. If the requirements for the selected upgrade type are not met, the game will display an error message. If no upgrade production facility is selected - the game sends the production order to any nearest unbusy production facility, otherwise it sends the order to nearest unbusy selected production facilities. It is impossible to create an upgrade production queue. To cancel upgrade production process, click "Mouse right button" on the upgrade icon or select production buildings and issue then "Cancel production (Ctrl+C)" order.

MAP SCENARIOS
* FFA(3)-FFA(8) - several free-for-all scenarios for different numbers of players; players team numbers can be changed.
* 1x1 - a classic 1x1 scenario;
* 2x2,3x3,4x4,2x2x2,2x2x2x2 - various team skirmish; players team numbers cannot be changed;
Objectives:
-Destroy all enemy players
* Key points - a tactical scenario in which players must capture 4 moving key points(see "im. #4 Key Points"). To capture a point, a player must have at least one unit inside it. Capturing a key point takes 10 seconds.
After capturing it, there is no requirement to keep units inside it.
Objectives:
-Capture all key points
* KotH (King of the Hill) - a tactical scenario in which players must hold the central area of the map(see "im. #5 KotH area") for 60 seconds. There is a 300-seconds cooldown before capturing the central area.
Objectives:
-Keep central area
* Royal Battle - a variant of free-for-all scenario, where the death circle gradually narrows the available space on the map.
Objectives:
-Stay alive
or
-Destroy all enemy players

NEUTRAL GENERATORS
Neutral generators (see "im. #3 Generators") - special objects on the game map that, when captured, increase "Energy level". There are 2 types of neutral generators:
- "Starter" generator - appears at players base in "Scirmish" game. Required at least 1 unit limit to be captured. Increase "Energy level" by 1000.
- "Normal" generator - appears at any map locations. Required at least 5 unit limit to be captured. Increase "Energy level" by 2000.
Both types of neutral generators requires holding units inside it, otherwise generator become back to neutral state.

RESOURCES
There are 3 types of resources in the game:
- The main resource of the game is the "Energy level". Almost all production (building construction, unit creation, or upgrade research) in the game consumes this resource. In the user interface, it is displayed as two numbers: the level of free energy and the maximum energy level. When a player starts any production that requires this resource, the game reduces the free energy level by the production cost and restores this amount after the production is completed. The energy level can be increased by specific buildings, as well as special objects on the game map that need to be captured and held.

There are also 2 additional types of resources used for special technologies and abilities:
- Hell power - when playing as the Hell faction, this resource is automatically replenished by the "Altar of Pain" building. The replenishment rate increases with each additional "Altar of Pain", but constructing more than 3 "Altars of Pain" does not provide any further benefit. When playing as UAC, the resource is generated from destroyed enemy units and Hell structures. Maximum quantity: 15000.
- UAC Loot - this resource is acquired by both factions through the destruction of enemy UAC units and buildings. Maximum quantity: 30000.

ARMY LIMIT
Each units and buildings in the game takes at least 1 limit point. Maximum limit points per each player is 125! Dead units still exist in the game and takes limit.

UNIT ATTRIBUTES
- ALIVE or DEAD;
- UNIT or BUILDING;
- MECHANICAL or BIOLOGICAL;
- LIGHT or HEAVY;
- FLYING or GROUND;
- LEVEL2..4 - unit level if it is higher than 1.

UNIT EFFECTS
- STUNED - unit is stuned and can`t attack or move;
- DETECTOR - unit can see invisible enemy units;
- HEROIC - unit is a hero; it deals 1.5 times more damage and takes a third less damage;
- SCANED - unit was scanned by UAC Radar;
- DECAY AURA - unit is under "Decay Aura" effect; it slowly lose health;
- HELL VISION - unit is under "Hell Vision" effect; it can see invisible enemy units;
- SOUL SPHERE - unit is under "Soul Sphere" effect; it`s regaining it health;
- INVULNERABILITY SPHERE - unit is under "Invulnerability Sphere" effect; it is immune to any damage;
- INVISIBILITY SPHERE - unit is under "Invisibility Sphere" effect; it invisibile;
- DAMAGE RESISTANCE SPHERE - unit is under "Damage Resistance Sphere" effect; it takes half damage and resist to "pain state" effect;
- DOUBLE DAMAGE SPHERE - unit is under "Double Damage Sphere" effect; it deals double damage;
- TURBO SPHERE - unit is under "Turbo Sphere" effect; its movement, attack, regeneration, production, construction and reloading speeds are doubled.

PAIN STATE
Some units have "Pain State" - it is a 1-second stun state after a certain number of damage hits. During the "Pain State" unit can`t attack or move. "Pain State" is accompanied by a special sound and unit animation.

VETERAN SYSTEM
All combat units gain combat experience and increase their level. All units spawn at level 1 and can be upgraded to level 4. With each new level, the unit increases its damage, armor, and pain threshold. The time in combat required to reach the next level varies for each type of unit(see "Units Info" section).

DAMAGE CALCULATION SEQUENCE
1) The game takes the attacking unit`s base damage and adds bonuses from upgrades and veteran level;
2) Special effects of the attacking unit that affect its damage amount are applied ("HEROIC" attribute and "DOUBLE DAMAGE SPHERE" effect);
3) A damage modifier for the attacking unit is applied to the resulting value;
4) Special effects reducing the received damage by the target unit are applied ("HEROIC" attribute and "DAMAGE RESISTANCE SPHERE" effect);
5) The armor of the target unit is calculated (bonuses from upgrades and its veteran level are summed up) and subtracted from the inflicted damage; if the damage drops below 1, it is raised to 1;
6) The target unit receives the final calculated damage.
Special cases:
- If the unit is a building under construction, steps 4 and 5 are skipped;
- Damage dealt by the "Decay Aura" effect also ignores points 4 and 5;
- Units with BUILDING or MECHANICAL attribute are immune to splash damage.

OTHER
If a player loses all his builders - all his units revealed on the map.

Unit hits regeneration period is 1 second.

DEDICATED SERVER

Dedicated server - a special version of the game that does not load any game resources and immediately starts working as a server. To start a dedicated server, run it with the following parameters:
MarsWars_ded.exe [X] [Y]

where X - UDP port (optional argument, default value - 10666); Y - LAN Advertise (optional argument, default value - 1 (true)).
Any connected player can change the game settings in a dedicated server`s lobby.
The game will start automatically as soon as all players mark the "ready" option. The server will return to the lobby one minute after the game ends or immediately after all players leave the server.

AI BOT SKILL LEVELS

AI1 - the easiest bot; AI9 - the the hardest.
AI1-5 - bot operates under the same conditions as a player-human; there are no unfair advantages and it does not ignore the fog of war; the difference is various size of army, super weapon or "magic" using, some micro-control abilities and build-order.
AI3+ - there is a chance of an early attack by a small group of units.
AI4+ - there is a chance of an super early attack by a first unit.
AI6 - AI5 + building construction speed is doubled.
AI7 - AI6 + upgrades production speed is doubled.
AI8 - AI7 + unit production speed is doubled.
AI9 - AI8 + bot can see enemy units or buildings, ignoring fog of war.
